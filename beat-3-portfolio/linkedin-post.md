I opened a PR for a feature request in NVDA, an open-source screen reader, to update a setting that previously limited how smoothly synthetic speech reads long text in a browser.

By expanding the maximum line length range from 10–250 characters to 0–1,000, users can now browse large paragraphs with fewer breaks, or select 0 to listen without interruptions. Contributing to this tool helped me broaden my horizons when it comes to interacting with my desktop without relying on a mouse or counting on my sight to navigate a website and reach the content I'm interested in.

Check out the PR here: https://github.com/nvaccess/nvda/pull/21105
